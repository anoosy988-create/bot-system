=========================================================
  SERVER SECURITY  -  طريقة الرفع الصحيحة
=========================================================

المشكلة اللي قبل:
  Error: Cannot find module '/home/container/index.js'

السبب: الملفات متحطّة داخل مجلد فرعي بدل /home/container


---------------------------------------------------------
  الطريقة الصحيحة (مهمة جداً)
---------------------------------------------------------

1. ادخل File Manager في WispByte وروح لمجلد:
       /home/container

2. احذف أي شي موجود (المجلدات القديمة مثل bot-system-main
   أو أي مجلد ثاني) عشان ما يصير تعارض.

3. ارفع ملف ال ZIP، وفك الضغط **داخل /home/container مباشرة**
   (مو داخل مجلد جديد).

4. بعد الفك لازم يكون الشكل كذا بالضبط:

       /home/container/
         ├── index.js          <-- لازم يكون هنا مباشرة
         ├── package.json
         ├── .env
         ├── tickets.js
         └── dashboard/
               ├── server.js
               └── public/
                     ├── app.js
                     ├── index.html
                     └── style.css

5. تأكد إن Settings>SprixEnvironment فيه:
       JS_FILE = index.js

6. شغّل السيرفر.


---------------------------------------------------------
  التحقق السريع (اكتبه في Console)
---------------------------------------------------------

    ls -la /home/container

لازم تشوف index.js و package.json و .env في نفس السطر.
لو تشوف مجلد فرعي (مثل bot-system-main/)، فك الضغط كان
غلط — كرر من خطوة 2.


---------------------------------------------------------
  بعد التشغيل بنجاح — امسح ملف ال ZIP (فيه مفاتيحك)
---------------------------------------------------------

    rm Server-Security.zip
